Laboratorio · ¿Funcionó la campaña?

40 minutos en clase + finalización autónoma. No necesitas programar. Trabaja en jamovi o SPSS con el mismo archivo.

⬇ Descargar datos_campana_CMU350.csv

Los 120 registros son sintéticos. No constituyen evidencia sobre consumidores reales.

1 · Importar y reconocer variables (0–10 min)

jamovi: abre el programa → menú superior izquierdo (☰) → Open / Abrir → This PC / Este equipo → selecciona el CSV. Comprueba que minutos_redes y gasto_mensual sean continuas y que vio_campana y compro sean nominales. El ID es identificador, no una variable para correlacionar.

SPSS: File → Import Data → CSV (o File → Open → Data, según versión). Marca que la primera fila contiene nombres de variables; revisa en Variable View que los tipos y medidas sean correctos.

Calcula las medias y desviaciones estándar del gasto por grupo: en jamovi Analyses → Exploration → Descriptives; coloca gasto_mensual en Variables y vio_campana en Split by. En SPSS Analyze → Descriptive Statistics → Explore.

2 · Pearson y dispersión (10–25 min)

Pregunta: ¿hay asociación lineal entre minutos diarios en redes y gasto mensual?

jamovi: Analyses → Regression → Correlation Matrix. Añade minutos_redes y gasto_mensual; selecciona Pearson, valor p y, si está disponible, gráfica de correlación. Para una gráfica de dispersión también puedes usar las opciones de Exploration o un módulo gráfico instalado, según versión.

SPSS: Analyze → Correlate → Bivariate → Pearson. Para la dispersión: Graphs → Chart Builder → Scatter/Dot.

Anota: r = ______ ; p = ______ ; ¿positiva o negativa? ______ ; ¿qué NO permite concluir? ______ .

3 · Diferencia de medias (25–33 min)

Pregunta: ¿difiere el gasto medio entre quienes vieron la campaña y quienes no?

jamovi: Analyses → T-Tests → Independent Samples T-Test. Dependent Variable: gasto_mensual; Grouping Variable: vio_campana. Selecciona Welch, descriptivos e intervalo de confianza. Verifica el orden de los grupos al leer el signo de la diferencia.

SPSS: Analyze → Compare Means → Independent-Samples T Test; en la configuración clásica, define los dos grupos y utiliza la fila «Equal variances not assumed» para el resultado tipo Welch.

Anota: medias ______ y ______ ; diferencia ______ ; p ______ ; intervalo 95% ______ .

4 · Asociación categórica (33–40 min)

Pregunta: ¿se asocia haber visto la campaña con haber comprado?

jamovi: Analyses → Frequencies → Contingency Tables → Independent Samples. Rows: vio_campana; Columns: compro. Activa chi-cuadrado, porcentajes por fila, frecuencias esperadas y V de Cramér.

SPSS: Analyze → Descriptive Statistics → Crosstabs. En Statistics activa Chi-square y Phi and Cramer's V; en Cells activa Observed, Expected y Row percentages.

Anota: χ² = ______ ; p = ______ ; porcentaje de compra en cada grupo ______ y ______ .

  2. Reporta los resultados de Pearson, Welch y chi-cuadrado con sus valores p.
  3. Explica qué significa cada resultado en lenguaje cotidiano.
  4. Escribe una recomendación para la agencia (máximo 150 palabras).
  5. Incluye al menos una limitación: muestra, diseño, datos sintéticos o causalidad.
